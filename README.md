# 🎪 大型活動行政管理工具 (Event Administration Management Tool)

> 參考 `indonesia-trip` 及 `vsbadge` 架構，結合 Google Sheet 與 Google Apps Script (GAS) 遠端控制，支援多活動接入、活動密碼私隱保護、7級角色權限控制與 8大卡片管理模組。

> 📖 **功能介紹及使用說明書**：見 [`docs/FEATURE_GUIDE.md`](docs/FEATURE_GUIDE.md)。APP 內亦提供「功能介紹」按鈕，不登入也可查看（三類卡片、各卡片功能、職級權限制度、可延展功能及 FAQ）。

---

## ✨ 系統核心功能特色

1. **多活動接入首頁 (Multi-Event Landing Page)**：
   - 可以在首頁看到多個不同的大型活動卡片（如：年度週年活動、領袖培訓、冬季大露營）。
2. **活動密碼私隱保護**：
   - 每個活動均可設定專屬密碼。首次接入時輸入密碼後將自動安全儲存於瀏覽器 `localStorage`，保障私隱。
3. **職級權限架構（L1–L7，對用戶顯示）**：
   - **Level 1**: 管理員 (地域 / 新職員 / 行政組)、主席、顧問 (同級，全部可看可管)
   - **Level 2**: 執行副主席 (高層統籌)
   - **Level 3**: 副主席 (各組別，因應活動設立)
   - **Level 4**: 總主任 (各組別，因應活動設立)
   - **Level 5**: 主任 (各組別，因應活動設立)
   - **Level 6**: 工作人員 (Staff)
   - **Level 7**: 公開 (Public，公開資料僅管理員以上可設定)
   - 👁️ **用戶管理可見範圍**：**執行副主席／主席／顧問／管理員**＝可見全部人｜**副主席**＝只睇自己組｜**總主任**＝自己組，唔包括副主席｜**主任**＝自己組普通工作人員。
   - 🚦 **批核權限表**：L1 或以上（管理員／顧問／主席／執行副主席）可查看及修改「批核權限表」，設定各申請範疇的批核組及執行／最後名單組。
   - ⚠️ **開戶權限**：前端開戶卡片只提供 工作人員／主任／總主任 三級；**籌委會架構 54 人已全部預先開戶**（顧問／主席／執行副主席／副主席／總主任／主任／秘書處管理員 5 人，見 `data/isd_2026.json` users + `data/committee_accounts.csv`），冇資料嘅可喺「用戶管理」／開戶表／批量 CSV 補。組別下拉（開戶/登記）不含「顧問團」及「主席及執行副主席」兩組。工作人員（數量多、名單後補）由各組自行開戶。
   - 📇 **部門管理中心 = 10 組**（含 顧問團、主席及執行副主席、秘書處，可查看/統計）。登入後儀表板順序：**公開資料 → 其他組別及工作卡片（會議卡片最前，自己組標亮）→ 管理工具（總主任以上）**；**我的監察**已寫入**身份卡片**內（自己＋下級申請批核進度，有權限人士另見總申請／待處理／已批核／已拒絕，可跳轉批核中心）。頂部 BAR＝身份・我的監察・介紹・改密碼・登出；手機底部導覽＝執行手冊・申請中心・批核中心・開戶（後兩者登入後有權限人士可見）。**未登入（一般工作人員／公眾）**＝只有**公告及溝通**及**申請中心**有顏色，其餘卡片無顏色（白底）。物資／泊車證／口頭報價／財務／**車輛** 均不另設獨立卡片，併入現有組別工作卡片（**泊車證沿用車輛申請路由**）。低於總主任的申請先由申請人本組總主任以上確認，再交目前設定的批核組；批核組及執行／最後名單組均可在批核權限頁以按鈕多選並隨時修改。
   - 📢 **公開區（4 張，登入前可看）固定排序**：公告及溝通（**已併入日程表／旅團須知／活動主題章**）→ **執行手冊**（**已併入組織架構與聯絡・場地與活動總覽・典禮儀式（含獲獎名單）・危機處理・通告及文件，內部分頁**）→ 申請中心 → 童心捐贈大行動（**統計只供服務及發展組／管理層查看**，公眾只可填表／掃碼）。
   - 👑 **典禮儀式卡片已內建官方定稿內容**（2026-10-04，不會再改）：典禮程序（10:45 嘉賓接待 → 11:00 吳家麗會長主禮優異旅團頒發 → 12:00 區永樑指揮官主禮會操檢閱 → 13:00 茶聚 → 14:00 主題活動區）及 嘉賓地圖（東閘入口／警校道／有蓋操場報到處／莫榮大樓接待處／海洋公園停車場／穿梭巴士）已直接內建於卡片，毋須連結 Drive。官方原圖 PDF（`assets/ceremony/guest_map.pdf`）可於「嘉賓地圖」分頁直接檢視／下載。
   - 📖 **會議議程／紀錄「內建 JSON」（免彈出 Google Drive APP）**：議程項目、議決事項及跟進事項已內建於 `data/meeting_records.json`，隨 APP 一齊發佈。會議卡片每張會議下面按「議程（內建·即睇）」／「會議紀錄（內建·即睇）」即喺卡片內展開**摘要／重點**（議程項目、議決事項、跟進事項），唔會跳去 Drive 或彈出 Drive APP；**要睇全文先按「睇全文（頁內開啟）」**（頁內 iframe 開原檔），亦可「下載原檔」或「Drive 開啟 ↗」跳轉（`downloadDriveFile` 用隱藏 iframe 下載，不開新分頁）。管理員可按「內建議程 JSON」直接編輯（存本機即時生效）並匯出覆蓋 `data/meeting_records.json` 發佈；`content_status` 標示「摘要／重點版」或「已錄入全文」。
   - 📁 **會議卡片直接開啟「會議 Drive」（即時連通）**：點入卡片即讀取公開資料夾 `13P0gJ3c-1zXTzniZFZL6VT2EZP_FDTYM`（定義於 `data/isd_2026.json` 的 `drive.groups.會議`／`meeting_upload_folder_id`），按分次子資料夾顯示議程、會議紀錄及附件，並可切換「清單／內嵌」模式。秘書處在 Drive 新增或更新檔案後，重新進入卡片或按「讀取最新」即可同步；GAS `listDriveFolder` 以 `UrlFetchApp` 公開讀取，資料夾及檔案須設為「知道連結的任何人可查看」。
   - 🗑️ **永久刪除申請紀錄**：物資、車輛／泊車及財務紀錄提供授權管理層刪除；刪除會同步至後台，並以本機刪除標記阻止舊快取或同步競態把紀錄重新顯示。後台工作表已刪除的申請亦以後台結果為準，不再被舊 `localStorage` 還原。
4. **8 大卡片管理模組**：
   - 📋 **1. 會議卡片**：會議紀錄、議程安排、各組會議摘要。
   - 👥 **2. 工作人員卡片**：組織架構、職員名單、職務大綱、聯絡資料。
   - 📁 **3. 文件檔案**：通告、保險相關文件與活動檔案。
   - 💰 **4. 財務管理**：活動預算、各組財政報告（參考印尼財務模版）。*已歸入「行政組」卡片，不另設獨立儀表板卡片（指引、預算、開支申報、口頭報價、結算批核均在行政組卡片內處理）。*
   - 🎪 **5. 活動與攤位**：攤位總覽、遊戲卡設計、地圖與活動項目。
   - 🍱 **6. 膳食管理**：登入訂餐、菜單及統計；預設行政組批核、協調組執行及持有最後名單，兩者均可改為多個組別。
   - 📅 **7. 日程表**：全活動時間表、各組行程與時段安排。
   - 📦 **8. 物資管理**：總物資清單及各組申請；依批核權限頁目前設定的批核組／執行組處理，會操及典禮組不會在未被明確指派時自動取得物資批核權。
5. **不改舊有資料的安全更新架構 (Non-Destructive Schema Update)**：
   - 後端 GAS 採用智慧結構檢驗 (`ensureSheet`)：當你新增功能或測試時，只會自動補齊缺失的欄位，**絕對不會覆蓋或刪除現有的工作表與舊資料**。

## 🚀 部署指南 (Deployment Guide)

### 第一步：設置 Google Sheet 與 Apps Script 後端
1. 在 Google Drive 建立一個新的 **Google 試算表**（例如命名為「活動行政管理總庫」）。
2. 點擊頂部選單的 **擴充功能 (Extensions)** ➔ **Apps Script**。
3. 清除編輯器中的預設程式碼，並將本項目中的 `apps-script/Code.gs` 完整貼上。
4. 點擊上方的 **儲存 (Save)** 按鈕。
5. 執行一次 `initializeSheets` 函數（點擊上方「執行」），授權權限後，它會建立／補齊所有系統工作表，包括 `Approval_Routing`、`Meal_Orders`、`Supply_Requests`、`Vehicle_Passes`、`Parking_Requests` 及 `Finance_Expenses`；此步驟不會重建已刪除的測試申請。
6. **部署為網頁應用程式 (Deploy as Web App)**：
   - 點擊右上角 **部署 (Deploy)** ➔ **新增部署 (New deployment)**。
   - 類型選擇 **網頁應用程式 (Web app)**。
   - 說明填寫 `v1.0`。
   - 執行身分 (Execute as)：**我 (Me)**。
   - 誰可以存取 (Who has access)：**任何人 (Anyone)**。
   - 點擊部署，複製產生的 **網頁應用程式 URL** (`https://script.google.com/macros/s/.../exec`)。

### 第二步：部署前端到 GitHub 與 Vercel
1. 將前端文件（`index.html`）上傳至你的 GitHub 倉庫。
2. 登入 [Vercel](https://vercel.com)，匯入該 GitHub 倉庫。
3. 部署完成後，開啟網頁。
4. 點擊右上角 **「⚙️ 系統設定 / GAS URL」**，將剛才複製的 **Google Apps Script URL** 貼上並儲存。
5. 即完成前後端完整聯動！你可以隨時測試新增會議、提交膳食申請、審批物資等功能，試算表數據實時同步。
