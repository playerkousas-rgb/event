功能介紹及使用說明

定位：「一個什麼都不知道的人，用此 APP 就可了解整個活動和找到需要的資料。」
公開查閱：所有公開資料無需登入即可查看；只有修改資料、提交申請、批核及開戶才需登入（一次登入永久有效）。

1️⃣ 現有功能：三類卡片

進入活動後，儀表板會根據身分顯示卡片。全部卡片一律白底無顏色（更整潔），只靠「可修改／只讀／公開可看」小標籤分辨，自己的組別會標亮。
排序：公開資料 → 工作卡片（會議卡片最前）→ 管理工具（總主任以上）→ 部門管理中心。
我的監察已併入頂部活動資訊橫幅（日期／時間／地點／天氣＋活動簡介＋最新消息同一橫幅內，一個用來跳轉的框：自己＋下級申請批核進度）；沒有批核權限人士只看到未有申請紀錄提示（身份喺最頂 BAR 右上角），可按鈕直接跳到「申請中心」提交；有權限人士另見總申請／待處理／已批核／已拒絕，點擊即跳轉批核中心處理。有批核權同時自己亦有申請的人士：四個數字＝自己＋下級合計，下方另有一行「我的申請」只計自己（含待處理數），點擊即到「我的監察」查看。
最頂 BAR（系統名稱那一行）＝身份・開戶（總主任以上）・改密碼・登出（登入後不顯示登入，只顯示登出；手機版無三畫功能鍵）；底部導覽列＝執行手冊・申請中心・批核中心・部門中心（批核中心登入後有權限人士才可見；部門中心登入後可見：執副以上一按即見全部部門列表、普通人一按直接跳自己部門），手機／電腦同步顯示。開戶已移去最頂 BAR 右側（登入後總主任以上可見，一按直接跳入開戶頁），儀表板管理工具區「開戶」卡保留作第二入口。

類型需登入？內容修改權限
我的監察需要併入頂部活動資訊橫幅（跳轉框）：自己＋下級申請批核進度；有權限人士另見總申請／待處理／已批核／已拒絕（可跳轉批核中心）只讀監察；批核在批核中心處理
我的組別需要已併入「工作卡片」，自己的組別標亮由組別權限決定
① 公開資料不用公告及溝通、執行手冊（組織架構・場地・典禮・危機・通告）、申請中心、童心捐贈只讀；修改需對應職級／組別登入
② 工作卡片需要會議、物資申請（地域借用）、攤位計劃書（獨立卡＋總表）、車輛通行證（含泊車證）、口頭報價、財務等預設只讀；依「可看／可管」權限解鎖
③ 管理工具需要開戶、批核中心、權限管理僅總主任以上可見／使用
④ 部門管理中心需要各部門專屬卡片，顯示本組統計與成員；崗位數／人數一律按「組織架構圖」計算，主頁卡片與進入卡片後兩處數字一致僅本組及管理員可修改

2️⃣ 主要功能：各卡片功能

公開類（無需登入可看）：公告及溝通（內含日程表・旅團須知・活動主題章）・執行手冊（內含組織架構與聯絡・場地與活動總覽・典禮儀式・危機處理・通告及文件）・申請中心・童心捐贈大行動（統計只供服務及發展組／管理層）。

卡片主要功能預設修改權限
公告及溝通公告、日程表、旅團須知、主題章；跨部門溝通、搜尋主任以上可發佈
執行手冊內部分頁：組織架構與聯絡・場地與活動總覽・典禮儀式・危機處理・通告及文件各頁按權限；公開可看
申請中心物資（地域借用）與攤位物資（向外判商租用）為兩項完全獨立的申請，另設車輛／泊車證、膳食、口頭報價、開支申報統一入口各表按權限進入
童心捐贈大行動物品／食品捐贈、QR Code 登記；統計只供服務及發展組／管理層服務及發展組可管理

工作／組別類（登入後按權限）：會議卡片・物資申請（地域借用）・攤位計劃書（向外判商租用帳篷／摺枱／摺椅，對標 2026 攤位總表，與物資申請完全獨立）・車輛通行證（含泊車證）・口頭報價登記・財務管理・行政組・協調組・顧問團・主席及執行副主席・會操及典禮組・主題節目組・品牌推廣組・嘉賓接待組・服務及發展組・秘書處。

管理／監察類：我的監察（自己＋下級申請進度）・批核中心（膳食／物資／車輛／財務）・批核權限表（設定批核組／執行組）・開戶（總主任以上）・權限管理（上級授權下級）。

申請表設計（一次申請多項，唔使重複填）：
• 物資申請：每項物資只填「名稱＋數量（＋單位）」，按「增加一項物資」繼續加；所屬組別／聯絡電話／申請原因是整張申請共用，只填一次，電話自動載入你登記時嘅聯絡號碼。
• 攤位計劃書＝獨立卡片＋公開可填寫（v8.7）：對標主題節目組「主題節目攤位計劃書」表單＋「2026 攤位總表」（分區＋編號＋負責單位選擇、攤位招牌名稱／活動內容／「十五五」主題自填、帳篷 3mW x 3mD／摺枱／摺椅只填數量、負責人姓名／年齡組別／單位／職位／WhatsApp／電郵）；「總表」頁籤按攤位匯總：TOTAL 總數（帳篷／摺枱／摺椅／圍布／電源）＋每個攤位一行明細，未提交攤位顯示「未提交」；與地域物資借用兩項紀錄完全分開。任何人無需登入都可提交（未登入請留姓名＋聯絡電話）；聯絡電話／電郵只供登入後查看。可匯出總表 CSV（Excel）。
• 膳食：菜單開放俾所有人填寫訂餐（無需登入，可選不吃）；菜單不設「組別」欄。公眾只見到「菜單＋我的訂餐」；訂餐紀錄/統計與列印派發只供本組總主任以上／批核／執行組。訂餐由本組總主任以上確認，再由指定組批核，最後由執行組落單派飯。
• 童心捐贈：公眾直接見到物品／食品兩張捐贈表（無須登入）；QR Code 下載同統計只列予服務及發展組／管理層。
• 返回：所有頁面頂部只有一個「← 返回」，一律＝返回上一層級（例如由申請中心入咗「物資申請」，撳返回就返申請中心，唔會跳晒返主頁）。

3️⃣ 各職級權限及權限制度

層級職級預設權限
L1管理員／主席／顧問全部可看可管；用戶管理＝可見全部人
L2執行副主席高層統籌；大部分可看可管；用戶管理＝可見全部人
L3副主席可更新日程／主題章／儀式／危機等；管理本組；只睇自己組
L4總主任可管理本組、申請、批核、開戶、報價；只睇自己組（不含副主席以上）
L5主任可管理本組內容、上傳活動、提交申請；只睇自己組工作人員
L6工作人員可登入、提交申請、查看自己組
L7公開只可看公開資料
  • 卡片可見度：minLevel=0 公開；minLevel>0 需登入且職級達標／屬指定組別。
  • 卡片修改權：達 editLevel 或屬 editGroups 才顯示「可修改」，否則「只讀」。
  • 角色授權：上級可透過「權限管理」設定用戶的「可看／可管」清單（perm_see／perm_edit）。
  • 開戶權限：前端開戶只提供工作人員／主任／總主任；副主席及以上由管理員處理；批量開戶管理員專用。
  • 批核權限表：L1 或以上（管理員／顧問／主席／執行副主席）可修改及使用「批核權限表」。
  • 批核路由：每類申請（物資／車輛／膳食／財務）可分別指定「批核組」（＝決定批唔批）及「執行／最後名單組」（＝批准後負責跟進、持最後名單），兩組都可多選、可隨時改。主任／工作人員提交後，先由所屬組總主任以上確認，再交指定批核組批核，批准後由指定執行組跟進。

4️⃣ 可延展的功能

  • 多活動接入／新增不同年度、類別的大型活動。
  • 通用化：把童軍專屬內容參數化，供其他活動類型重用。
  • 動態批核路由：按銀碼、組別、日期等條件自動分流。
  • 細粒度權限授權：每一張卡片、每一個動作皆可授權。
  • 統計儀表板：跨活動匯總、圖表、匯出。
  • 文件／Drive 自動同步、版本記錄、全文檢索。
  • 批量匯入人員／物資／財務／攤位／日程。
  • 全域搜尋擴充為跨卡片全文檢索。
  • 離線／快取同步，後端自動補齊欄位（不會覆蓋舊資料）。
