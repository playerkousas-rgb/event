## 2. MOCK（模擬示範版）開放全部管理權限

**背景**：用戶要求「MOCK 應該把所有管理權限都開放出來」——示範沙盒嘅身份切換不應受限於角色。

- `demoLogin()`（示範登入一鍵切換）及 Mock 模式本地登入：currentUser 帶 **`mock_admin: true`** 標記；任意姓名登入預設系統管理員
- 權限判斷統一尊重標記（只影響示範登入者自己，正式活動帳戶完全不受影響）：
  - `roleLevel()`：登入者自己 role → 100（`canSeeRoleCard`/`canEditRoleCard` 全部卡片解鎖）
  - `isAdmin()`／`isSuperAdmin()`／`isEventManager()` → true
  - `canManageApprovalRouting()`／`canApproveArea()`／`canExecuteArea()` → 批核權限表、各範疇批核全開
  - `canSeeAllUsers()`／`canSeeUserPasswords()`／用戶管理開任何職級／批量開戶（`canBulkOnboard`）／組織架構執行副主席以上視角
- 登入提示及「身份登入」彈窗標明「🔓 MOCK 示範登入已開放全部管理權限（本地沙盒）」
