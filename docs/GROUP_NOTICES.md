# 📢 各組資料更新通知（WhatsApp／電郵版）

> 用法：以下每段分「WhatsApp（短版）」和「電郵（正式版）」，可直接複製轉發給各組負責人。
> 核心訊息：**各組只要在 Drive 內更新 Google Sheet 表單，APP 開啟即自動同步最新資料**，無需逐項通知系統管理員。

**WhatsApp（短版）**
```
各位負責人好！膳食、物資、車輛通行證、開支等申請，

```

**電郵（正式版）**
```
致：各功能組別負責人

關於「港島童軍繽紛日 2026」膳食、物資、車輛通行證及開支的申請安排：

由即日起，上述申請一律透過活動管理系統（APP）內建表單辦理：
1. 膳食：登入後於「膳食」卡片提交；低於總主任先由本組確認，再交動態膳食批核組（預設行政組），批准後由執行組（預設協調組）取得最後名單。
2. 物資：於「申請中心」提交；低於總主任先由本組總主任以上確認，再交批核權限頁目前設定的物資批核組，批准後由設定的執行組取得最後名單。
3. 車輛／泊車證：於「物資+車輛」卡片登記車牌及司機，沿用同一車輛動態路由；預設協調組批核及執行，但可多選其他組並隨時修改。
4. 開支：於「財務」卡片填表並上傳單據，按銀碼門檻批核。

提交後，你可隨時於「我的監察」卡片查閱自己項目的處理狀態（待批／已批）及內容，無需另行查詢。
```
