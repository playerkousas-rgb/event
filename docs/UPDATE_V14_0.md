## 2. 四張名單的「格式」（預定欄位；Excel／Word 匯入即照此對位）

欄位定義集中喺 `js/00-config.js` 的 `ROSTER_LIST_DEFS`（`columns`＝欄位、`match_fields`＝點名配對欄、`aliases`＝匯入時認嘅表頭）。**所有名單的最後一欄永遠係「TICK（點名）」＋「點名紀錄」。**

## 3. 上傳名單：EXCEL／WORD／PDF（同一個入口）

每張名單嘅工具列都有：

| 按鈕 | 行為 |
|---|---|
| **上傳名單（EXCEL／WORD／PDF）** | `.xlsx/.xls/.xlsm/.csv` → SheetJS 讀第一張表，按表頭（中／英文 aliases）對位；`.docx/.doc` → mammoth：**優先讀 Word 內嘅表格**（`<table>`），冇表格時按「換行＋Tab／多空白／逗號」拆行；`.pdf` → 無法可靠解析行列，會**自動改做附件內嵌預覽**並提示用 EXCEL／WORD 或「貼上文字」。 |
| **貼上文字（由 PDF／網頁複製）** | 喺 PDF／網頁選取名單（連表頭嗰行）複製 → 貼入 → 即時生成行列（每行用 Tab／兩格以上空白／`,` 分隔）。呢個係只有 PDF 檔時最快嘅做法。 |
| 匯入預覽 | 一定先彈預覽：顯示解析到幾多行／首 60 行、揀「**取代**」或「**附加**」；內容欄位相同嘅行會保留原有 TICK。 |
| **上傳附件（PDF／Word／圖片／Drive 連結）** | 沿用執行手冊上傳機制（同「遊戲卡」一樣）：Word 解析成文字內嵌、PDF 整份內嵌、圖片直接睇、可貼 Drive 連結；有版本欄、可下載／刪除。 |
| 下載格式範本 CSV | 按「預定格式」產生表頭＋兩行樣板，用家照樣板填好回覆上即成。 |
| 匯出 CSV／列印點名表 | 匯出連 TICK 狀態、點名時間、點名人；列印用既有 `printCoordArea`（A4 表格）。 |
| 同步名單至後端／由後端取回 | 已設 GAS 連線時可用（行內容＋TICK 狀態一次過推；取回時 upsert，唔覆蓋本地較新嘅 TICK）。 |

## 4. 點名（做法完全對標「優異旅團 FULL LIST」）

* TICK 勾選即時儲存；**取消 TICK 必須輸入更正原因**（無填就彈返原狀），原因會顯示喺「點名紀錄」欄並寫入後端 `correction_cancelled=Y`。
* 進度列：`已點名／總數`；分組 chips（支部獎勵＝按支部、領袖獎勵＝按獎項、參加旅團＝按支部、代訂餐盒＝按區會），每組顯示 `d/n`，全部 TICK 完可以做「**確認**」（寫入 `Roster_Rollcall_Batches`，顯示 ✅已確認）。
* 排序：按區會／支部／旅團／姓名（或該名單嘅欄位）＋「未點名優先」＋順序／倒序（↕）。
* 「全選本欄點名」：一次過 TICK 目前篩選結果（用於大批派發），仍需確認。
* 後端：每筆 TICK 寫 `Roster_Rollcall_Checkins`（同優異旅團一套）；GAS 端有「**只接受較新操作**」防護，避免舊裝置把新更正覆寫。

## 5. 權限（誰可改、誰可點名）

| 動作 | 誰可以 |
|---|---|
| 檢視名單 | **所有人（公開，無需登入）** |
| 上傳／編輯／刪除名單、上載附件、後端同步 | 管理層（super_admin／admin）、副主席以上（level ≥ 60）、**該名單負責組別內主任以上（level ≥ 30）**；行政組依 v8.14 慣例可統管全站名單 |
| 點名 TICK | 上述人士 ＋ **該負責組別任何已登入成員**（現場由本組工作人員逐個 TICK）；未登入／冇關組別只能睇 |
| 參加旅團名單嘅「名單本身」 | 仍由行政組經 Drive 同步或 Excel 上載（`handleParticipantsExcelUpload`／`handleParticipantsUploadFile`）；點名入口喺同一頁 |

判定函數：`rosterCanManage(key)`／`rosterCanTick(key)`（`js/41-roster-lists.js`）。附件區權限（`roster_<key>`）由 `canManageExecManualUpload()` 交返比同一個判定，唔會另外開一套。
