## 1. 點解要搬上嚟

你講嘅舊流程係咁：

```
地域網頁下載紙本表格 → 手寫捐贈者名單 → 當日連貨交到櫃位
   → 工作人員逐張點人數同件數 → 派章
```

三個痛點，全部喺櫃位先爆：

| 痛點 | 以前 | 而家 |
|---|---|---|
| **帶錯貨** | 到咗場先知唔合規格（過期、玻璃樽、散裝米、二手文具）→ 白行一趟 | 喺手機揀計劃嗰一刻，即刻見到「✓ 收呢啲／✕ 唔收呢啲」同規格 |
| **紙表甩漏** | 寫漏捐贈者姓名 → 派唔到章（紀念章係按名單逐位派） | 填咗件數但冇姓名，即時紅字提你 |
| **櫃位塞車** | 人手加人數、加件數、數應派幾多枚章 | 自動計：位數・件數・應派章數，一眼睇晒 |

## 2. 新流程（公眾睇到嘅嘢）

公眾頻道 → 揀身份（旅團／優異旅團／步操隊伍／其他制服團體／支部最高獎勵／成人獎勵）→ 頁簽 **❤ 童心捐贈**：

1. **幾時・邊度交** — 2027-10-03（日）11:00–15:00・警察學院有蓋操場收集攤位・由旅團負責領袖收齊一次過交。
2. **揀計劃**（兩張卡，一眼見到受惠機構同收／唔收摘要）
   - 🍚 **食品捐贈** → 循道衛理觀塘社會服務處
   - 📦 **物品回收** → 國際十字路會
3. **合規格自我檢查** — 入去即見完整 ✓ 收／✕ 唔收清單＋黃框「計唔計得數」規格。
4. **捐贈者名單** — 一行一位（姓名＋件數），可以隨時 ＋ 加一位／刪一行。
5. **即時核對** — 底下三個大字：`N 位捐贈者 / M 件 / K 枚紀念章`；夠 200 件自動彈特別紀念章提示。
6. **登記 → 捐贈單** — 出一個編號（`DF2027-xxxx` 食品 / `DG2027-xxxx` 物品）＋摘要，寫明「到場報呢個號或出示屏幕」。
7. **紙本照收** — 底下一直有「下載紙本捐贈表格」，唔用手機嘅照舊得。

> **冇 QR Code。** 跟返你定嘅規矩，公開頁唔出 QR——捐贈單淨係編號＋摘要。

## 3. 規格（原文照搬 2026 兩份特別通告）

### 🍚 食品捐贈 — 循道衛理觀塘社會服務處

- **收**：已包裝食米（1–2 公斤）・粉麵類（上海麵／米粉／粉絲／公仔麵／通心粉）・餅乾類・非玻璃容器食油・燕麥片・湯料（中藥材類）
- **唔收**：已拆封或損毀・已變質・冇商標標貼・散裝食米・熟食・奶類製品・罐頭類・玻璃容器
- **規格**：最佳食用日期須 **2028-06-01 或之後**（2026 原文係 2027-06-01，示範版順延一年）・每件 **≥ 75 克**・必須有獨立食品標籤及最佳食用日期先計數
- **紀念章**：每位捐贈者 1 枚；**同一位捐贈者／單位 > 200 件 → 額外特別紀念章及感謝狀**

### 📦 物品回收 — 國際十字路會

- **收**：電腦相關用品（滑鼠／鍵盤／顯示器／充電用品，全新或狀態良好）・具教育意義玩具（如 Lego）・全新學校文具・狀態良好英語兒童讀物
- **唔收**：已損壞電器・殘舊或缺頁書本・非英語兒童讀物・二手文具
- **規格**：**學校文具以 10 件為 1 個單位**，夠 1 單位先計 1 枚章
- **紀念章**：每位捐贈者 1 枚

## 4. 後台點接

捐贈單**唔係另起爐灶**，直接寫入現有嘅「童心捐贈大行動」模組（`js/38-donations.js`），格式完全一樣：

```js
{ id, no, scout_group, leader_name, leader_position, leader_phone, leader_email,
  date, items:[{name:'陳大文', quantity:12}, …], source:'公眾頻道・手機預填' }
```

→ 籌委開「童心捐贈大行動」卡，即刻見到「N 人捐贈 · 共 M 件」，同以前人手入嗰啲混得埋一齊，匯出 CSV 都一次過。

多咗個 `no`（捐贈單編號）同 `source` 欄；舊紀錄冇呢兩個欄位都照顯示，唔會爆。

## 7. 要你決定／跟進

1. **嘉賓入口要唔要都加？** 而家 6 類參加者有，**嘉賓冇**（嘉賓流程係接待→嘉賓席→自助餐，唔經收集攤位）。你話要就一行搞掂。
2. **紙本表格 PDF 連結** 而家指去 `hkirscout.org.hk` 主頁（示範）；正式版要換成實際 PDF。
3. **收集攤位位置** 寫咗「有蓋操場收集攤位」；攤位總表落實咗攤位編號之後，可以直接寫明「X 區 X 號攤位」。
4. **日期規則** 食品最佳食用日期示範版寫 2028-06-01（2026 原文 2027-06-01 順延一年），正式版由服務及發展組確認。
