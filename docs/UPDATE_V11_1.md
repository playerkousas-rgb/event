## 1️⃣ 箱頭紙改用**指定式樣**（年份 2025 → **2026**）

原本自訂版面（年份／活動／組別／負責人／聯絡／內容物／數量／備註）已**改為地域指定式樣**，
內容與 Drive 提供之樣本一致，只係年份改為 **2026**：

```
            香港童軍總會　港島地域
        港島童軍繽紛日 2026 物資
  組別：______ 組    負責人／攤位名稱 __________
  數量：___ / ___   （序號 / 需運送物資總數）
  ┌───────────────────┬──────────────────────────────────────┐
  │ ☐ 去程 (4/10/2026) │ 百週年紀念大樓 → 香港警察學院          │
  ├───────────────────┼──────────────────────────────────────┤
  │ ☐ 活動完結         │ ☐ 香港警察學院 → 百週年紀念大樓        │
  │                    │ ☐ 自行運走　☐ 棄置　☐ 交地域處理       │
  └───────────────────┴──────────────────────────────────────┘
```

| 項目 | 說明 |
|---|---|
| 年份 | 由活動 `start_date` 自動帶出（現為 **2026**），亦可手改；改年份時去程日期即時同步 |
| 去程日期 | 跟活動首日自動計算，按式樣格式 `d/m/yyyy`（**4/10/2026**） |
| 組別 | 預設為你的登入組別（部門中心入口亦會帶入該組） |
| 序號 / 總數 | 對應式樣「數量：__ / __（序號 / 需運送物資總數）」 |
| 活動完結 | 四選一：香港警察學院→百週年紀念大樓／自行運走／棄置／交地域處理，列印時打實心方格 |
| 列印 | **一張 A4 上下印兩張 A5（每張 210×148.5mm）**，中間有虛線剪開線，用戶自行剪開，慳紙環保 |

程式：`js/26-monitor-apply.js` — `boxLabelFormHTML` / `boxLabelSheetHTML` / `boxLabelTripDate` / `printBoxLabels`。

## 2️⃣ 失物認領：**兩種登記情況**

| 類別 | `type` | 開啟狀態 | 完成狀態 | 情境 |
|---|---|---|---|---|
| ① 有失物登記 | `found` | 待認領 | **已認領** | 拾獲物品交來行政組，等物主出現 |
| ② 有人要尋找物品 | `seeking` | 尋找中 | **已尋回** | 失主報失，等物品出現 |

登記表單會按類別自動轉換字眼（拾獲日期／遺失日期、拾獲人／尋物者……）。

## 3️⃣ 兩張列表 + 點入處理認領 + **自動紀錄時間**

- 下方**分開兩張列表**：「① 失物登記列表」及「② 尋物登記列表」。
- 行政組成員**點擊任何一行**（或按「處理認領」）即開處理視窗：
  - 失物 → **找到物主** → 按「確認認領」→ 狀態轉 **已認領**
  - 尋物 → **尋回失物** → 按「確認尋回」→ 狀態轉 **已尋回**
- ⏱ **所有時間全部系統自動紀錄，毋須人手填寫**：
  - `created_at` — 登記嗰刻自動記低（兩種登記都有）
  - `claimed_at` — 確認認領／尋回嗰刻自動記低，同時記低處理人 `closed_by`
  - 「取消完成」會清走完成時間並回復開啟狀態
- 列表同時顯示登記時間、完成時間及處理人；CSV 匯出亦包含以上欄位。

程式：`js/39-lost-found.js` — `openLostFoundForm(type,id)` / `openLostFoundClaim(id)` /
`confirmLostFoundClaim()` / `reopenLostFound(id)` / `lostFoundNowStamp()`。
