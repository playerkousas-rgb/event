# 2027 欄位合約表（階段 0 藍圖）

> **用法**：先完成最終成品（公眾頻道＋執行手冊），由成品倒推每個欄位由邊張報名表／邊個組產生。
> 呢份表一鎖定，之後全部照圖施工。**下屆籌委新增活動＝複製範本，直接可用。**
>
> 狀態：**v0.1 草稿**（待批核）｜素材基礎：2026 真實資料（通告 12/26・司儀稿 Rundown V5・DGA 名單・嘉賓名單 CSV・UG 清單）

## 0. 設計原則（2026 教訓 → 2027 規則）

| # | 2026 現況 | 2027 規則 |
|---|---|---|
| 1 | 素材冇框架，原始人唔知件嘢用嚟做乜 | **格有名字**：每筆資料有佢喺最終頁面嘅「格」，表單開頭就講明「你填嘅嘢會出現喺執行手冊邊頁」 |
| 2 | WhatsApp 噴一堆，Drive 自動更新冇人用 | **表單即入口**：資料只從報名表／維護頁入；WhatsApp 只做提醒鈴（深連結入表單），永不做倉庫 |
| 3 | 檔案 R2 R3 版本地獄 | **紀錄代替檔案**：一筆紀錄原地修改，`updated_by／updated_at` 自動留痕，冇「版本」呢回事 |
| 4 | 同步功能被迫全停，全手動收尾 | **空殼先行・自動着燈**：手冊頁面由紀錄自動渲染，冇料嘅格顯示「未提交」，邊個未交一目了然 |
| 5 | 手稿對手稿，四個源頭對唔到數 | **一條血脈**：通告→報名→確認→名單→手冊→點名，全部同一份紀錄 |

## 1. 資料流（一條血脈）

```
特別通告（sp 通告）
   └→ 八大報名表（公眾免登入，資料即入系統）
         └→ 確認／名額（行政組極簡後台：待確認→已確認）
               └→ 名單（自動生成，唔使人手砌）
                     └→ 執行手冊／公眾頁（自動渲染，空格=未提交）
                           └→ 活動日（點名／派發／報到，同一筆紀錄）
                                 └→ 完場（凍結，成為下屆示範資料）
```

## 3. 八大報名表欄位定義（全部免登入）

共通機制：提交即出**申請編號**｜狀態 `submitted → confirmed → final`｜`updated_by／updated_at` 留痕｜公眾用「編號＋電話」查進度｜所有改動原地改，冇新版本。

### 3.1 旅團報名 `troop_registration`
| 項目 | 內容 |
|---|---|
| 對象 | 旅領袖（每旅最少 1 領袖帶隊） |
| 欄位 | 旅號・團（可多團）｜區會（旅號帶出）｜領隊姓名・職位・電話・電郵｜各支部成員人數｜家長親友人數｜**代訂餐盒數量**（總額上限 700・$60/份）｜旅遊巴（是/否＋到達/離場時間）｜家長同意書 PT/46 確認｜費用自動計（$10×人數） |
| 上限 | 名額 2,000（先到先得）・餐盒 700 |
| 去重 key | 旅號＋團 |
| 產生 | 參加旅團名單・代訂餐盒名單 |
| 2026 例子 | 通告 12/26＋旅團報名人數.xls |

### 3.2 優異旅團報名 `merit_troop`
| 項目 | 內容 |
|---|---|
| 對象 | 獲獎旅團領袖（種籽名單由典禮組預載＝DGA 名單） |
| 欄位 | 旅號・團｜出席人數｜派隊人數（步操）｜彩帶/證書領取安排（小童軍＝證書；幼童軍/童軍/深資/樂行＝彩帶） |
| 產生 | 優異旅團獲獎名單（＋出席點名） |
| 2026 例子 | DGA list（柴灣/港島北/港島南/港島西…7 區） |

### 3.3 嘉賓報名 `guest`
| 項目 | 內容 |
|---|---|
| 對象 | 獲邀人士／秘書處代填 |
| 欄位 | **照 2026 嘉賓名單 CSV 欄位直接照搬**：姓名・職銜・機構・第一部分典禮・第二部分典禮・茶聚・乘坐大會車・**車牌**・飲食需要・備註 |

### 3.6 支部最高獎勵獲獎人士報名 `section_award`
| 項目 | 內容 |
|---|---|

| 欄位 | **照 ROSTER_LIST_DEFS `leader_award`**：唱名序・區會・單位・職級・姓名・獎項（總監委任書/10 年長期服務獎狀/長期服務獎章/一星/三星/領袖及委員獎勵）・需覆誓・出席・備註 |
| 產生 | 領袖獎勵獲獎名單（＋上台點名） |
| 2026 例子 | 司儀稿：10 年獎狀×7・獎章×3・一星×1・三星×1（部分「未能出席」——報名先知） |
