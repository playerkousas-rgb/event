# v15.1（2026-10-02）— 節目 2025／2026 資料混雜清理 ＋ 2026 資料凍結

## 問題根源（點解「節目」會 2025 同 2026 混埋？）

檢查過 Drive 同後端 Google Sheet（「Event System」）後確認：

1. **後端 `Activities` 分頁積咗 17,100 行 booth 紀錄**（正常應該得 33 行）。
   - 舊版前端每部機每次開 APP 都會自動由 Drive 同步攤位，然後用**全新隨機 id**
     （`booth_<timestamp>_<random>`）逐個 POST 寫入後端 → 由 8 月 20 日起不斷重複疊加。
   - 早期同步來源係「ISD2025 攤位資料（參考）」→ 大量 **2025 攤位**（永續航跡、毒悔終生、
     保護兒童…）同後期嘅 **2026 攤位**（機電先鋒、十五五與我好有關…）全部混埋一齊。
   - v15.0 嘅 `import2026Data` 又寫入咗一批 `booth_001–031`，但 `data/isd_2026.json`
     入面嘅攤位本身解析錯位（欄位移咗行），寫入嘅都係亂碼資料。
2. 前端「節目／攤位」由後端 Sheet 讀**所有** `type=booth` 紀錄 → 畫面顯示 2025＋2026 混雜。
3. 副作用：`getEventData` 回應脹到 ~9MB，全場 APP 開得好慢。

## 已修復

### ① `data/isd_2026.json` — 攤位資料重新解析（33 個）
- 由 Drive「ISD2026 攤位資料.xlsx」**2026 分頁**重新逐欄對齊：
  分區／編號（A01–F06）／主題範疇／負責單位／攤位名稱／預計內容／聯絡人／
  攤位負責人及電話／工作人員數目／Lunch／確認出席。
- 只收錄有編號嘅確認攤位；**2025 參考資料一律唔會再入**。
- `data_version` 已升級，客戶端會自動棄用舊快取。

### ② `apps-script/Code.gs` — 一次過清理後端（v15.1）
新增 `rebuildBooths2026()`：**一次過**刪走 Activities 分頁所有 isd_2026 嘅 booth 紀錄
（整表重寫，17,000 行都唔會超時），再寫入 33 個 2026 正式攤位（已內嵌喺 Code.gs）。

**執行步驟（必須做一次）：**
1. 開 Apps Script 編輯器 → 貼上新版 `Code.gs` → 儲存。
2. 「部署 → 管理部署 → ✏️ 編輯 → 版本：**新版本** → 部署」。
3. 瀏覽器開（一條 URL 搞掂）：
   ```
   <GAS網址>/exec?action=rebuildBooths2026&api_key=<API_KEY>
   ```
   見到 `{"success":true,"removed":17100,"written":33,...}` 即完成。
   （亦可直接喺編輯器 Run `rebuildBooths2026`。）

另修正 `saveBooths` 舊 bug：以前會連非攤位嘅活動紀錄一齊刪。

### ③ 2026 資料凍結（活動前最終版 — 只可下載／列印）
新增 `DATA_FROZEN_EVENT_IDS=['isd_2026']`（`00-config.js`）＋ `app.isDataFrozen()`：

| 範圍 | 凍結後 |
|---|---|
| 攤位（節目） | 新增／編輯／刪除／上傳 Excel／Drive 同步按鈕全部隱藏兼封鎖；只以 Google Sheet 正式資料顯示；**下載範本以外，列印照用** |
| 地圖／遊戲卡／活動列表 | 上傳／修改封鎖（`canUploadActivity`） |
| 文件檔案／主題章 | 上傳封鎖（`canUploadDocument`／`canUploadThemeBadge`） |
| 工作人員（架構圖／名單） | 上傳 Excel／檔案按鈕隱藏兼封鎖 |
| 日程表 | 上傳 Excel 封鎖 |
| 參加旅團名單 | 上傳 Excel／Word 封鎖 |
| 預算 | 上傳 Excel 封鎖 |
| 名單引擎（嘉賓／優異旅團等） | **整批上載／貼上文字**封鎖；**點名、逐行新增（現場加名／替補）、匯出、列印照用** |
| 開支申報／物資申請／失物／紀念章 | **唔受影響**（活動日運作功能） |

- **ISD 2027 唔喺凍結名單**，所有上載功能保留，供未來籌備。
- 同時堵塞咗污染源：凍結活動唔會再逐個攤位 POST 去後端，亦唔會由 Drive xlsx 自動同步蓋過正式資料。

### ④ Drive
- 「節目組」資料夾入面嘅捷徑 **「ISD2025 攤位資料(參考)」** 由第三者帳號擁有，
  API 無權刪除（403）— 請資料夾管理員喺 Drive 右鍵「移除」。
  （就算唔移除，APP 已經唔會再讀 2025 資料。）
- `ISD2026 攤位資料.xlsx` 內部仍有 `2025ref` 分頁，純屬人手參考；APP 只讀 `2026` 分頁資料。
