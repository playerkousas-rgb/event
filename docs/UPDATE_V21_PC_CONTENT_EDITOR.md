# v21 — 公眾頻道內容：各組自己改，唔使搵人

## 要解決嘅問題

v20 之前，公眾頻道 2027 嘅 **32 個頂層區塊 100% 由 `tools/build_pc2027_demo.js` 產生**。
即係話：捐贈收咩唔收咩、午膳幾點、嘉賓幾點到、熱線電話——
**籌委想改一個字，都要搵人改程式再重新產生 JSON。**

呢個就係「搞上我」最大嗰舊。亦都係 2026 年失敗嘅機制起點：

```
冇框 → 人隨意改 → 對唔上 → 自動更新失效 → 要人手夾 → 愈夾愈遲 → 當日仲改
```

v21 由另一邊入手：**畀佢哋自己改，但只准喺框入面改。**

## 做咗啲咩

### 1. 一條界：內容開放，結構鎖死

| | 由邊個話事 | 喺邊度改 |
|---|---|---|
| **內容**　文字、時間、地點、清單 | 負責組 | APP：部門中心 → 🌐 公眾頻道內容 |
| **結構**　分眾入口、頁簽組合、欄位名、名單點連 | 技術組（我哋） | `PC_CONTENT_SCHEMA` |

`PC_LOCKED_KEYS`（15 個 key：`audiences`／`section_labels`／`guides`／`manual`／`guests_rows`／`staff_gate` …）
**就算 override 入面有都唔會生效**——組點改內容都整唔爛個版。

### 2. 表單由 schema 自動生成

`js/47-pc-content-editor.js` 入面 `PC_CONTENT_SCHEMA` 一份嘢做三件事：

1. **生成表單**——每格邊種輸入框、點排、點驗
2. **寫死擁有權**——`owner:'服務及發展組'` 決定邊組見到邊格
3. **就係欄位合約本身**——唔使另外維護一份文件

所以 schema 同表單同合約**永遠唔會脫節**，因為佢哋係同一份嘢。

支援 5 種欄位型別：`text`／`textarea`／`list`（一行一項）／`pairs`（`項目 | 內容`）／`objlist`（結構化清單，逐格填）。

### 3. 14 個區塊，按組分好

| 負責組 | 負責區塊 |
|---|---|
| 行政組 | 活動基本資訊・求助・報到 QR 規則・共同須知 |
| 協調組 | 全日程序・交通與入場・午膳安排 |
| 會操及典禮組 | 典禮儀式流程・座位表・午膳儀式（嘉賓） |
| 嘉賓接待組 | 嘉賓專屬安排・嘉賓最後一分鐘變動 |
| 服務及發展組 | 童心捐贈 |
| 秘書處 | 通知書規則 |

行政組同管理層見到全部（統籌角色）。冇負責內容嘅組，個頁籤根本唔會出現。

### 4. 改動點樣流返出去

```
組喺 APP 改  →  overrides（localStorage，按 event_id）
                      ↓
              pcDemoData() 開頁時疊一次
                      ↓
    公眾頁 7 類入口 ／ 執行手冊 ／ 工作人員頁  全部即刻用新內容
```

- **唔會寫 `data/mock_demo.json`**——凍結來源檔完全唔郁，隨時「還原預設」。
- **原地改，唔出版本**——每格記低 `by` ／ `at`，冇 R2 R3 R4 final 呢啲嘢。
- 非 mock 環境會 best-effort POST `module:'PublicChannelContent'`（接口**標住**，照約定今年唔駁）。

### 5. 欄位合約可以機械抽取

```bash
node tools/dump_field_contract.js            # Markdown（已產生 docs/2027_PC_FIELD_CONTRACT.md）
node tools/dump_field_contract.js --csv      # 畀籌委／試算表
node tools/dump_field_contract.js --json     # 程式用
node tools/dump_field_contract.js --check    # 核對每條路徑接唔接得到資料
```

呢個就係第 2 步（回追源頭）嘅起點：**邊格要邊個欄位，係由程式抽出嚟，唔係靠人諗。**
`--check` 現時：✓ 66 條路徑全部接得到 `data/mock_demo.json`，零死路徑。

## 仲未做（故意）

- **加／減項目**（例如多一個捐贈計劃、多一行程序）暫時只可以改現有嗰幾項，加減要搵管理員。
  原因：加減會影響其他地方點連，要先確認冇嘢跌。
- **凍結線**（過時之後嘅改動另標為「增補」）——`docs/2027_FIELD_CONTRACT.md` 已有「原地改」同「冇料寫未提交」兩條，凍結線未做。
- **後端儲存**——照約定，今年只要畫面出到結果，接口標住唔駁。
