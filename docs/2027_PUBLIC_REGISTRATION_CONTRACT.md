# 2027 公眾報名資料合約（MOCK）

## 目的及現況

這是 2027 活動的最小公開登記入口：任何人毋須登入，按自己最接近的類別提交一次報名。所有類別最後都是同一個 `isd2027.public_registration.v1` 記錄；不設部門各自的表格、名單或主資料副本。

本合約目前只在 MOCK 前端實作。提交會保存於該瀏覽器，用作演示欄位、統計和後續輸出的關係；它不是正式跨裝置收集，亦未建立 Google Sheet、GAS 或後端。

## 公開選擇的四類登記者

| 登記類別 | 誰填寫 | 會提供給系統的資料 |
|---|---|---|
| 童軍旅／參加單位 | 領隊或單位負責人 | 單位及聯絡人、總人數和青少年／成人／親友組成、活動／典禮參與安排、餐盒和飲食／無障礙需要、到達方式、車輛及時段 |
| 嘉賓／獎勵得主 | 本人、受邀機構或獲授權代填人 | 身分／獎項及聯絡、典禮或活動出席安排、同行及餐飲需要、交通、車輛和無障礙需要 |
| 合作機構／其他制服團體 | 機構或隊伍負責人 | 機構和聯絡人、參與形式和出席人數、攤位／服務／表演安排、餐飲、交通、車輛和特別需要 |
| 家長／親友／個人參加者 | 成年人代表 | 聯絡人、總人數及未成年同行人數、相關單位、餐飲、無障礙需要、到達方式和車輛需要 |

每類均只收集活動安排所需的資料，並要求同意私隱聲明。健康、無障礙及個人聯絡資料必須以私隱資料處理；公開及一般工作人員的摘要只顯示匯總數字。

## Canonical registration record

每次提交建立一筆以下形狀的標準記錄：

```text
schema, registration_id, registrant_type, status, submitted_at, source
contact { name, phone, email }
organisation { name, type, area }
attendance { total, youth, adult, family, mode }
needs { meal_count, dietary, accessibility, activity }
transport { mode, vehicle_count, arrival_note }
notes
field_values
```

`field_values` 保留原來表單中只適用於某類別的欄位一次；共同資料會正規化到 `attendance`、`needs` 和 `transport`。因此之後的點名、膳食、交通／泊車、典禮和報表可從同一記錄讀取，而不應另製平行名單。

## 目前可以產生的非私隱摘要

- 各類別：提交份數、出席總人數
- 全體：出席人數、餐飲份數、申報飲食需要份數、申報無障礙需要份數、申報車輛數量

共享資料庫、確認／審批狀態、正式通知、付款及活動日點名的具體流程，保留至公開輸出與必要欄位確認後才設計。
