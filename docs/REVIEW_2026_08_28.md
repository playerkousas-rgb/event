## 1. 所有「要確認」嘅嘢有冇防呆機制？（怕 SAVE 唔到後台）

### 先講清楚而家嘅儲存架構（重點：唔會「存唔到」）
成個 APP 嘅申請／批核都係**雙寫**：
- **即刻寫入本機 localStorage**（實質係「第 1 重存檔」，永遠成功）；
- 之後 **best-effort 同步去後台 GAS**（第 2 重，失敗唔會丟資料，只係其他裝置暫時睇唔到）。

所以**唔會「SAVE 唔到後台」就成個冇咗**——你嗰部機一定存到。真正風險係「其他裝置／重新載入後睇唔到」。

### 我今次搵到同修好嘅 3 個真問題
1. **攤位計劃書跨裝置睇唔到（最大）**：前端一直有把計劃書寫出後台 `Booth_Requests`，但**後台 `getEventAllData` 根本冇回傳呢張表、前端同步亦冇合併** → 其他籌委／另一部機睇唔到人哋交嘅計劃書。已修（見第 4 點）。**要重新部署 Code.gs + 行一次 initializeSheets 先生效**（`Booth_Requests` 表 schema 一早有）。
2. **大量「確認／拒絕」動作冇確認框**：膳食一鍵審批、一鍵本組確認、拒絕物資／攤位／車輛／泊車／開支，之前一撳即做、冇得反悔。已全部補 `confirm()` 確認框。
3. **開戶同級漏洞**（見第 2 點）。

### 建議（冇改，想同你講）
後台同步係「send-and-forget」，若後台真係連唔到，畫面上仍會顯示「成功」（本機已存），但其他裝置會睇唔到。現時設計刻意咁做（本地一定有），正式場合建議：確認 GAS 網址正確、部署存取權限係「任何人」、重啟 Code.gs 後再實測一次跨裝置。

## 2. 開戶功能：總主任／副主席開本組主任＋普通工作人員，對嗎？

**係，確認你嘅理解正確。** 依家權限如下：

| 開戶人 | 可開（本組） |
|---|---|
| 副主席（L3，60） | 總主任、主任、普通工作人員 |
| 總主任（L4，40） | 主任、普通工作人員 |
| 管理員／執行副主席／超管 | 跨組、全部職級 |

- 非管理層**只能幫自己組**開戶（組別下拉鎖死）。
- 職級下拉只提供 **工作人員／主任／總主任**；副主席及以上由管理員處理。
- 預設密碼 1234。

**順手修正咗一個漏洞**：之前 `總主任` 可以開**另一個總主任**（同級），同你講嘅「只開主任＋普通工作人員」唔一致。我已經喺前端 `submitAccountSetup` 同後端 `createAccount` 都收緊為**「唔可以開層級等同或比自己高」**——即總主任只開主任／工作人員，副主席可以開總主任／主任／工作人員。**要重新部署 Code.gs 先生效**。

## 3. 未登入填申請：籌委睇到邊個申請，但我自己喺「我的監察」睇唔到？

**係，完全正確，全部符合預期：**

- ✅ **未登入可以填**：膳食訂餐（「填寫訂餐（無需登入）」）同攤位計劃書（「公開可填寫（無需登入）」）都唔使登入。
- ✅ **負責籌委睇到邊個**：兩張表都**記低咗姓名／組別／負責人／電話**。
  - 膳食：訂餐表強制填「姓名＋組別/攤位」，訂餐紀錄／統計（本組總主任以上、指定批核組、執行組）睇到邊個訂。
  - 攤位：計劃書強制填「負責人姓名＋年齡＋單位＋職位＋電話＋電郵」同「提交人姓名＋電話」；籌辦方喺「計劃書明細」／「借用統計＋招牌」／「執行手冊 → 攤位總表」全部睇到。公眾（未登入）睇總表時**負責人電話／電郵會隱藏（🔒）**，只有登入人士睇到。
- ✅ **你（未登入）自己睇唔到自己申請喺「我的監察」**：因為「我的監察」**要登入**先顯示；未登入狀態下頁面會叫你先登入。呢個係正確／預期行為。
  - 貼士：膳食另有一個「**我的訂餐**」分頁，唔登入都顯示「此裝置」訂咗啲乜（按瀏覽器記住 order id）。

### 已檢查冇發現重大問題
- **登入流程**：帳號／電郵／中文姓名都可登入，密碼已 `trim`，舊版部署有「重新部署」提示。
- **必填驗證**：膳食（姓名／組別／選擇）、物資（名稱＋數量>0＋組別）、攤位（分區／單位／招牌名／內容／十五五／負責人全套／未登入另要提交人＋電話）、開支／報價／泊車，全部有擋，填漏唔會空提交。
- **用戶可見範圍**：副主席睇本組／總主任睇本組（唔包副主席）／主任睇本組 staff，與 README 一致。
- **批核路由**：膳食預設行政組批、協調組執行；物資／車輛協調組；可多選組別、須按「確定更新」先生效。
- **Mock 示範版**：mock_admin 全權限只喺示範沙盒，正式活動唔受影響。

1. 喺 Apps Script **重新部署**（部署 → 管理部署 → 新版本）。
