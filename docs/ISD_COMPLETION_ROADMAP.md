# ISD 完成路線圖 - 一步一腳印先完成 ISD，後續通用版再完善

> 用戶：你現在已經看到過 ISD 的執行手冊了，我想我們現在一步一腳印先完成 ISD 的，後續的大型活動通用版本再慢慢完善，ISD 你看這麼多年其實整個形式 RUN DOWN 也差不多的

## ISD 形式分析 (多年 RUN DOWN 差不多)

根據 2017 工作人員手冊、2023 毅行執行手冊、2025/2026 ISD資料，ISD 每年流程相似：

```
07:45 - 08:30  會操及頒獎禮場地設置劃位，各功能組別場地佈置 (協調組：場地佈置、物資運送)
08:30 - 10:30  參加旅團報到 / 步操比賽後備日，制服團隊報到 (步操及典禮組：貼嘉賓座位紙、營座點算，節目組：攤位負責人報到佈置)
11:00 - 12:00  優異旅團及獎勵頒發典禮：主禮嘉賓檢閱、頒發彩帶及證書、支部最高獎章嘉許信、領袖獎勵
11:15 - 12:30  步操檢閱及頒獎典禮：檢閱步操隊伍、禮步致敬、幼童軍團呼、頒發升國旗儀式比賽、步操比賽獎項、棍禮致敬
12:30 - 14:00  午膳 (食堂A/B)、節目展覽 (有蓋操場)
13:00 - 16:30  攤位博覽與積極公民工作坊，領袖聯誼閣運作，禮物換領
16:30 - 17:30  所有節目完結、拆卸設施、清潔、運送物資、對數 (常務組往 Burger King 對數)
```

**工作人員日程是重點**：2017 手冊有時間 x 組別交叉表 (時間、協調組、步操及典禮組、節目組、服務組、行政組)，讓各組一目了然自己何時做什麼，這正是舊 Google Sites 缺乏的「以看的人為中心」。

## 已完成卡片 (v7.3 前)

- 會議、手冊、財務、物資+車輛、膳食、活動與攤位、主題章、文件、行政組、協調組、安全、日程、公告、用戶批量

這些已能覆蓋舊手冊大部分，但日程表之前僅 4 行簡單版，未體現每年差不多且詳細的 Run Down。

## 本次升級：日程表 (ISD Run Down)

**目標**：讓什麼都不知道的人用此 APP 就可了解整個 ISD 流程和找到需要的資料，且各組一眼看到自己何時做什麼

**實作 (v7.4)**：

- **總表 (參加者視角)**：07:45-17:30 6 段，時間、位置、節目，與 2017 版一致，公開可看
- **工作人員日程 (時間×組別交叉表)**：參考 2017 手冊，表格頭：時間、協調組、步操及典禮組、節目組、服務組、行政組，每格填寫該組該時段任務，例如 07:45 協調組場地佈置、08:30 步操報到處 set up，一目了然，解決舊版分散查找
- **典禮程序**：10:30-12:30 優異旅團頒獎 + 步操檢閱詳細流程，含司儀稿、獲獎名單提示 (舊版 2017 有 10-33 頁司儀稿、獲獎名單，可在文件卡片上傳)
- **Word 上傳轉日程**：支援上傳 Word 用 mammoth 解析，轉文字存 localStorage，管理員可上傳往年 Word 日程自動轉
- **列印、匯出**：可列印總表供派發

## 下一步：ISD 一步一腳印完成計劃

按「方便更多工作人員看和查找資料、籌委各組更方便協作和統計、什麼都不知道的人可了解整個活動」方針，建議逐張卡片深化：

### 優先順序 (ISD 核心)

1. **日程表 (已完成基礎，需深化)**：已完成 Run Down，下一步加入各組截止日期提醒、倒數、與會議 Banner 連動
2. **場地與攤位 (活動與攤位卡片)**：已完成地圖、攤位總表、遊戲卡，需深化：加入 ISD 2026 具體攤位資料 (從舊版 Copy of ISD2025 攤位資料)、場地總圖高清版、攤位設備清單 (2017 手冊有 38-40 頁)、車位一覽表 (41頁)、許可證式樣
3. **會操及典禮 (可新增卡片或深化日程)**：步操檢閱司儀稿、優異旅團獲獎名單、支部獎勵、領袖獎勵、典禮流程，可從 2017 手冊 30-33 頁範例轉入
4. **行政組 (已初步)**：需深化：活動通告、報名表、參加旅團名單 (20251012版)、膳食安排圖、急救申請，參考舊手冊行政組頁
5. **協調組 (已初步)**：需深化：場地佈置圖 R7、物資借用表格 v.3 Fillable、箱頭紙、佈置數據 Spreadsheet，參考舊手冊協調組頁
6. **膳食、物資、車輛 (已完成，含截止日期)**：需測試 ISD 2026 實際數據，確保截止後鎖定、監察卡片可用
7. **財務 (已修正批核鏈)**：需匯入 ISD 2026 真實預算，測試報價門檻
8. **危機處理**（已併入原「安全及醫療」）：2026 版已依 2025 手冊更新日期、小組成員及聯絡；保險文件、意外通報指引可於「應變指引 → 保險／急救」持續補充（2017 手冊 46-49 頁）
9. **泊車證申請（已完成）**：所有人可申請，行政副主席/執行副主席/主席/顧問/秘書處(管理員)/超管批核，Google Sheet 總表內置讀取
10. **公告及溝通**：用於 ISD 期間跨組協作，例如 場地佈置完成通知、膳食派發通知等

### 通用版再完善 (ISD 完成後)

- 將 ISD 專屬欄位 (例如 警察學院、步操檢閱) 參數化，變為可配置活動類型
- 儀表板按活動類型顯示不同 Run Down 範本 (ISD、毅行、賽船大會等)
- 統計儀表板：參加人數統計 (如毅行手冊的 1338人統計表)、膳食統計、物資統計
- 實用連結、QR code (如毅行手冊有 Facebook tag、追蹤連結)

## 定位重申

**APP 定位**：方便更多工作人員看和查找資料，籌委各組之間更方便協作和統計資料，一個什麼都不知道的人用此 APP 就可了解整個活動和找到需要的資料

- **公開查閱**：無需登入即可查看所有資料，僅修改需登入，一次登入永久有效 (localStorage)，已在 Hero 提示
- **按組別一目了然**：部門管理中心自動提取組別，顯示本組控制內容，僅本組或管理員可修改
- **卡片分類**：分 4 大類 (認識活動、參與活動、後勤支援、協作與管理) 13張卡，一眼看到分類
- **全域搜尋**：搜尋會議、文件、財務、物資、膳食、地圖、攤位、公告等
